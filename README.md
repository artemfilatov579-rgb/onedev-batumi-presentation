### Как получить PDF

Лендинг содержит готовую печатную вёрстку (14 страниц A4), поэтому PDF делается
прямо из браузера:

1. Откройте `index.html` (или [живую страницу](https://artemfilatov579-rgb.github.io/onedev-batumi-presentation/))
2. Нажмите **Ctrl+P** (на Mac **Cmd+P**)
3. Destination / Принтер — **Save as PDF**
4. Margins / Поля — **None**
5. Обязательно включите **Background graphics** / «Фоновая графика»
6. Save

Интерактивный калькулятор в PDF автоматически заменяется на статичную таблицу
с расчётами по всем объектам — это заложено в print-вёрстку.

## Важные оговорки по данным

Эти ограничения заложены в калькулятор намеренно — чтобы он не показывал цифр,
которых нет у застройщика. Если будете переиспользовать данные, сохраните их.

**1. Тип аренды доступен только там, где есть расчёт застройщика.**
Ramada и HOME — только краткосрочная аренда. ONE и Stay & Rent — только долгосрочная.
Второй вариант в калькуляторе заблокирован с пояснением. Ставок для него застройщик
не публиковал, и придумывать их нельзя.

**2. По SportCity доходность и рост стоимости не опубликованы.**
Калькулятор показывает только цену входа, на месте доходности — прочерк.
Встречающаяся у брокеров оценка «до 15% годовых» — это НЕ цифра застройщика.

**3. Уровни отделки опубликованы только для ONE.**
Белый каркас +$150/м², чистовая +$600/м², под ключ +$750/м² — от чёрного каркаса.
Для остальных объектов выбор отделки в калькуляторе скрыт.

**4. Доходность считается от полной суммы вложений.**
При выборе неполной отделки калькулятор добавляет стоимость доведения квартиры до
сдаваемого состояния. Иначе получалась бы ложная картина: цена ниже, а арендная
ставка как у готовой квартиры.

**5. Прирост при перепродаже считается от заявленного процента роста**, а не из цены
за м² к сдаче — та относится к другому уровню отделки и давала завышенный результат.

**6. Все показатели доходности и роста — прогноз застройщика, а не гарантия.**
Прошлый рост не гарантирует будущий. Цены и наличие лотов меняются.

## Дизайн-система

Оформление наследует дизайн-систему [realmajor.life](https://realmajor.life):
бордовая палитра — отсылка к цвету грузинского вина (саперави).

| Токен | Значение | Где |
|-------|----------|-----|
| `--wine-400` | `#E0568A` | акценты, цифры, ссылки |
| `--wine-600` | `#A81E48` | кнопки, активные состояния |
| `--wine-700` | `#7D1435` | выделенные показатели |
| `--wine-800` | `#5A0E26` | выбранный объект в калькуляторе |
| `--ink-950` … `--ink-850` | `#0A0710` … `#171021` | фоны секций |
| `--surface` … `--surface-3` | `#1C1426` … `#2E2140` | карточки и контролы |
| `--fog-100` … `--fog-600` | `#F2EDF5` … `#7D7088` | текстовая шкала |

Шрифты: **Bricolage Grotesque** (заголовки, 800/600), **Inter** (текст),
**JetBrains Mono** (лейблы и подписи, трекинг `.09em`).
Радиусы 20/12/10px, анимация `380ms cubic-bezier(.16,1,.3,1)`.

Контраст текста проверен по WCAG: основной текст на всех фонах ≥ 4.5:1.
